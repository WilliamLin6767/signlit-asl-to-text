# Third-party components

Signlit's app and temporal decoding are new code. The ASL classifier is a
pretrained third-party model, not a model trained by the author of this app.

## ASL skeleton CNN

- Author: Nicolás Florentín (`punpuniacitizen`).
- Source: https://github.com/punpuniacitizen/MediaPipe-ASL-sign-language-recognition
- Asset: `asl_cnn_model.onnx`; 96×96 RGB skeleton input, 26 output logits.
- `dist/renderer.js` adapts the geometry, palette, and drawing order of the
  upstream `preprocessing.py` to browser Canvas. Canvas and OpenCV rasterizers
  differ; Signlit performs its own smoke checks rather than claiming upstream
  evaluation results as measurements of this web app.
- Upstream source code: MIT, copyright (c) 2026 Nicolás Florentín.
- Upstream weights are explicitly excluded from its MIT license. The model
  was trained on ASL Alphabet by Akash Nagaraj (GPL-2.0), ASL Dataset by Ayush
  Thakur (CC0-1.0), and ASL Alphabet Test by Dan Rasband (CC0-1.0).
- Weights are downloaded by the setup script and excluded from source commits.
  Consult the upstream README and dataset terms before redistributing weights.

## Hand tracking and inference

- MediaPipe Tasks Vision and Google's hand-landmarker model: Google / MediaPipe,
  Apache-2.0. https://github.com/google-ai-edge/mediapipe
- The skeleton color palette originates in MediaPipe `drawing_styles`,
  Apache-2.0. https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/python/solutions/drawing_styles.py
- ONNX Runtime Web: Microsoft, MIT.
  https://github.com/microsoft/onnxruntime
- Runtime license files are retained in each vendor directory during setup.

## Recorded demonstration

- Handshape photographs: ASL Dataset by Ayush Thakur, CC0-1.0.
  https://www.kaggle.com/datasets/ayuraj/asl-dataset
- The app replays hand landmarks extracted from those real photographs.
  Predicted labels come from the model; they are not hard-coded in the demo.
- Blank frames used between signs are generated by Signlit.
